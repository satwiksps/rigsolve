# Examples

These examples are intentionally review-first. None pipes a generated plan directly into a shell.

- [`targeted-solve.sh`](targeted-solve.sh) creates plans for a machine you do not currently have.
- [`known-broken.toml`](known-broken.toml) is a complete mini-matrix template for a negative fact.
- [`verification-contribution.md`](verification-contribution.md) walks through creating and reviewing local verification evidence.

Examples track the current CLI but the compatibility matrix evolves. Inspect `rigsolve matrix stats` and the tier header in every generated plan.
